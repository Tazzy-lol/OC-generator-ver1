# OC Generator

A tiny Python project that creates random characters with unique vibes, powers, and weapons.

## Features
- Random OC generation
- Unique powers and personalities
- Different weapon types
- Easy to customize and expand

## Example Output

```txt
=== YOUR OC ===
Name: Luna
Power: Shadow magic
Personality: Chaotic
Weapon: Scythe
```

## Built With
- Python
- random module
